2 Score of each supplier on each attribute

Weights of the attributes inside each group come from Tables 2 and 3. The three suppliers' scores on each attribute come from Tables 4 to 9 (opinions) or, on the right, from measured values where they exist.

Measured values used (lower is better)

Score = (1/x) ÷ Σ(1/x), so the real ratio is kept. Quality uses the bad-part rate, because the cost of poor quality comes from the bad parts (S3 sends 2.25 times as many as S1). The paper gives only ranges; values per supplier are placed inside the paper's range following its ranking (estimate). You can type real company values.

3 Final score = Σ (global weight × score)

Global weight = group weight (w or 1 − w) × weight inside the group. Every product is shown; the last row adds each column.

4 Flip point: the weight w at which the winner changes

Each final score is a straight line in w. w* = [S1(0) − S2(0)] ÷ ([S1(0) − S2(0)] − [S1(1) − S2(1)]).

5 How sure is the winner? (random trials)

Each trial: every answer moves by −1, 0 or +1 step, w is random between 0.1 and 0.9 (right side: measured values also vary ±5%). Fixed seed, so the result repeats exactly.
